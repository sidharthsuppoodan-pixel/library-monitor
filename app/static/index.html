Set up your library sensor

  1. 01

    Configure the ESP32

    Copy config.example.h to config.h in the Arduino sketch folder. Add your Wi-Fi credentials and the server’s device key.

  2. 02

    Set your HTTPS endpoint

    Set API_URL to your deployed Render URL followed by /readings. Add the correct root CA certificate.

    Local dashboard addresses are for computer testing. The supplied firmware requires HTTPS.

  3. 03

    Upload and verify

    Select ESP32 Dev Module in Arduino IDE, upload the sketch and open Serial Monitor at 115200 baud. HTTP 201 means a reading was stored.

Readings appear automatically after your device connects.
See docs/HARDWARE.md for the wiring guide.
